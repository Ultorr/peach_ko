# Peach 선택·별점 UI

## 1. 분위기
기존 Peach의 조밀한 미디어 목록, 폴더 도구 모음과 하단 선택 작업대를 유지한다.

## 2. 색상
`--ink`, `--ink-2`, `--surface`, `--ground`, `--line`, `--muted`, `--tungsten`, `--control-hover`를 재사용한다. React 영역은 BoardUI 의미 토큰을 사용한다.

## 3. 글꼴
기존 `--board-body`, `--board-body-medium`, 제목·본문·캡션 스타일을 사용한다. 한국어 문장은 단어 단위로 줄바꿈한다.

## 4. 배치
폴더 도구 모음은 기존 `folder-scope-row`의 줄바꿈과 간격을 사용한다. 모달은 공유 `formModal`의 본문·하단 작업 영역을 사용한다. 선택 작업대는 좁은 화면에서 줄바꿈한다.

## 5. 재사용 구성 요소
- BoardUI Button·Checkbox: 기본·선택·포커스·비활성·읽는 중 상태.
- SelectionDock: 선택 개수, 작업 버튼, 취소. 선택 없음은 숨김.
- formModal: 제목, 설명, 네이티브 라디오, 진행 상태, 기존 오류 표시, 적용·취소. 저장 중 점수 변경을 막는다.
- DataTableFrame·목록 체크박스: 개별 선택과 Shift 범위 선택. 영상 열기는 기존 이름 버튼에 유지한다.

## 6. 상호작용
일괄 적용은 지정한 점수로 덮어쓴다. 같은 점수를 다시 지정해도 해제되지 않는다. 해제는 별도 0점 선택으로 제공한다. 폴더 읽기는 탐색 시 취소한다. 저장 실패는 완료 개수와 재시도 대상을 유지한다.

## 7. 표면
기존 `batch-dock.css`, BoardUI, 공유 모달의 경계·그림자·배경을 재사용한다. 새로운 장식 효과를 추가하지 않는다.

## 8. 접근성
체크박스와 라디오는 키보드로 조작할 수 있다. 모달의 초점 관리와 Escape 처리는 공유 구성 요소를 따른다. 진행 수치는 live status로 알린다. 데스크톱과 390×844에서 버튼과 한글 줄바꿈을 검증한다.
